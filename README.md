# 3D Portfolio Website

A modern, interactive portfolio website built with React, Three.js, and GSAP, featuring stunning 3D animations and a responsive design.

![Portfolio Preview](/public/images/readme.png)

## 🌟 Features

- Interactive 3D room scene with dynamic lighting
- Animated tech stack showcase with 3D models
- Responsive design that works on all devices
- Smooth animations and transitions using GSAP
- Professional project showcase with detailed case studies
- Client testimonials section
- Contact form with email integration
- Performance optimized 3D models and textures
- Social media integration
- Modern UI/UX with attention to detail

## 🛠️ Technologies

- **Frontend Framework:** React 19
- **3D Graphics:** Three.js, React Three Fiber, React Three Drei
- **Animations:** GSAP
- **Styling:** TailwindCSS
- **Build Tool:** Vite
- **Email Integration:** EmailJS
- **Development Tools:** ESLint

## 📦 Installation

1. Clone the repository:

```bash
git clone https://github.com/yourusername/3d-portfolio.git
cd 3d-portfolio
```

2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

4. Build for production:

```bash
npm run build
```

## 🚀 Usage

The website consists of several sections:

- **Hero Section:** Features an interactive 3D room scene
- **Work Showcase:** Displays recent projects and achievements
- **Experience:** Details professional experience with company logos
- **Skills:** Shows technical expertise with 3D animated icons
- **Testimonials:** Client reviews and feedback
- **Contact:** Email contact form with social media links
